### What I've built

- **[SmartRoute](https://github.com/AnmolSrivastavaaaa/SmartRoute)**: an LLM gateway that sends each request to the cheapest model that can handle it, escalates when quality drops, fails over across providers, and caches answers. Comes with a live analytics dashboard. *FastAPI, PostgreSQL, Redis, React, Groq, Gemini*
- **[SmartDocs](https://github.com/AnmolSrivastavaaaa/SmartDocs-documents-with-AI-intelligence-LLM-python)**: upload your documents and ask questions about them. Retrieval-augmented generation with a model that runs locally, so the documents never leave your machine. *ChromaDB, Sentence-Transformers, PyTorch*
- **[financial-pdf-analyzer](https://github.com/AnmolSrivastavaaaa/financial-pdf-analyzer)**: a backend API that reads financial PDFs and pulls out structured management insights. *Python*
- **OCR-KYC pipeline** (built at Scalean): turns ID documents into structured records in 1–2 seconds per document. *PaddleOCR on GPU, FastAPI, TypeScript*
- **Instagram DM agent**: an n8n agent that replies to my DMs in my own style and pings my phone when a message needs me. Has handled 1,000+ DMs. [Read the post](https://www.linkedin.com/posts/anmolsrivastavaaaa_n8n-aiagents-automation-activity-7515506624262770688-I0cz)
